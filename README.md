# 이름 궁합 (Name Match)

두 이름의 **오행(五行)** 으로 궁합을 점쳐보는 웹 게임입니다. React + Vite로 만들었고,
계산 로직은 DOM 없이 순수 함수로 분리돼 있어 Node로도 바로 테스트할 수 있습니다.

## 데모

**https://hololol815.github.io/name-match/**

##玩法 (사용법)

1. 두 이름(한글, 6자까지)을 입력하거나 **🎲 상대 랜덤 뽑기**로 상대 이름을 받습니다.
2. **궁합 보기**를 누르면 0~100점의 궁합 점수와 등급이 나옵니다.
3. 결과는 **카드 저장**(PNG) 또는 **텍스트 복사**로 공유할 수 있습니다.

## 궁합 계산 방식

이름을 한글 유니코드 순서(`가`~`힣`)에 따라 **목(木)·화(火)·토(土)·금(金)·수(水)** 오행에
배정합니다. 같은 글자는 언제나 같은 오행을 갖습니다.

점수에 영향을 주는 요소:

| 요소 | 효과 |
| --- | --- |
| 첫 글자 오행 | 같은 오행 +8, 상생(相生) +16, 상극(相克) −16 |
| 첫 글자 ↔ 상대 마지막 글자 | 상생이면 +9 |
| 겹치는 오행 | 오행 1개당 +4 (최대 +20) |
| 이름 길이 | 동일 +6, 1자 차이 +2 |
| 공통 글자 | 1개당 +5 (최대 +10) |
| 받침 유무 | 둘 다 있거나 둘 다 없으면 +4 |
| 이름 해시 | −5 ~ +5 (같은 조합은 항상 같은 결과) |

상생: 목생화 · 화생토 · 토생금 · 금생수 · 수생목
상극: 목극토 · 토극수 · 수극화 · 화극금 · 금극목

등급은 90점 천생연분 / 80점 오래가는 인연 / 70점 서로를 아는 사이 / 55점 편한 친구지간 /
38점 연애보다 우정 / 그 외 아직 인연이 아니에요 입니다.

### 점수 분포

무작위 4,000쌍 기준 (중앙값 62점, 범위 21~93점)

| 등급 | 비중 |
| --- | --- |
| 천생연분 | 0.1% |
| 오래가는 인연 | 2.9% |
| 서로를 아는 사이 | 21.3% |
| 편한 친구지간 | 36.0% |
| 연애보다 우정 | 20.0% |
| 아직 인연이 아니에요 | 19.7% |

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드
npm run lint     # 린트
npm run deploy   # 빌드 후 gh-pages 브랜치로 배포
```

## 구조

```
src/
  game/
    elements.js     # 오행 배정 · 상생/상극 · 점수 계산 (순수 함수)
    shareCard.js    # 결과 카드 PNG 생성(Canvas) · 공유 텍스트
    validate.js     # 이름 입력 검증
  components/
    NameForm.jsx    # 이름 입력 폼
    ResultView.jsx  # 결과 화면 (점수 링 · 오행 분포 · 사유)
  App.jsx / App.css
```

> 팬메이드 재미용 결과이며 실제 인연과 관계없습니다.
